# ITSX26_team_hastarna_malmo
Intro:
Uppdragsgivaren är ett mellanstort svenskt företag med drift i molnet och krav på att kunna visa vem som gjort vad i efterhand. I dag är internnätet platt, alla servrar når varandra och loggarna ligger kvar lokalt på respektive maskin. Teamet får i uppdrag att segmentera miljön enligt Zero Trust-principer, sätta upp central loggning med säkerhetsövervakning och dokumentera lösningen så att uppdragsgivarens egen driftpersonal kan ta över den.
